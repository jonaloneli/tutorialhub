Archivo local detectado

Firebase no funciona con archivos locales (file://). Usa una de estas opciones:

  • VS Code: Instala "Live Server" y haz clic derecho → "Open with Live Server"
  • Python: Ejecuta: python -m http.server 8000
  • Sube a Netlify: Arrastra el archivo a netlify.com (gratis)
